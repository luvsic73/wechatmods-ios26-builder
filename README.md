# WeChatMods iOS 26 Builder

Minimal public CI builder for the local project.

- Compiles the arm64 loader with Xcode 26.2.
- Runs the no-account iOS 26.2 Simulator fixture on iPhone 17 Pro Max.
- Publishes only the compiled loader and simulator diagnostics.
- Contains no IPA, credentials, account data, or proprietary app binary.
